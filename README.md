**Planet Explorer** is an interactive 3D application developed using Python, Pygame, and PyOpenGL. It provides an engaging interface where users can select planets and explore their 3D models with mouse-controlled rotation and zoom functionality.

---

## ✨ Features

- **Interactive Home Screen**
  - Displays planet thumbnails.
  - Hover effects and clickable planet selection.

- **Dynamic 3D Rendering**
  - Texture-mapped 3D planet visualization.
  - Mouse-controlled rotation.
  - Scroll-controlled zoom functionality.

- **Seamless Navigation**
  - Switch between the home screen and 3D planet view.
  - Press `ESC` to return to the home screen.

## 🔧 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/shohelrana68/Planet-Explorer.git
cd Planet-Explorer
```

### 2. Install Dependencies

```bash
pip install pygame PyOpenGL PyOpenGL_accelerate
```

### 3. Run the Application

```bash
python Planet_explorer.py
```

---

## 🎮 Controls

| Action | Control |
|---|---|
| Select a planet | Left mouse click |
| Rotate planet | Hold and drag left mouse button |
| Zoom in | Scroll up |
| Zoom out | Scroll down |
| Return to home screen | ESC |
